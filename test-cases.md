# Login Functionality — Test Cases

## TC-001: Successful login with valid credentials

**Objective:** Verify that a registered user can log in successfully.

**Preconditions:** The user has an existing account.

**Test steps:**
1. Open the login page.
2. Enter a valid email address.
3. Enter the correct password.
4. Click the Login button.

**Expected result:** The user is logged in and redirected to the appropriate page.

**Status:** Not executed

## TC-002: Login with an incorrect password

**Objective:** Verify that the system rejects an incorrect password.

**Preconditions:** The user has an existing account.

**Test steps:**
1. Open the login page.
2. Enter a registered email address.
3. Enter an incorrect password.
4. Click the Login button.

**Expected result:** The user remains logged out and sees an appropriate error message.

**Status:** Not executed
