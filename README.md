Hi, I'm a Product Manager with experience in software quality assurance, user acceptance testing (UAT), test case design, and defect reporting.

This repository showcases examples of my approach to testing software, documenting expected behaviour, identifying defects, and improving product quality.

- Manual software testing
- Test case design and documentation
- Functional testing
- User acceptance testing (UAT)
- Bug reporting and defect documentation

## Testing Approach

My approach to QA focuses on understanding requirements, validating expected behaviour, documenting test results, and communicating defects clearly so that product and engineering teams can make informed decisions.
